### How to read this file

- Numbers are PvE values. Where the perfect version differs, it is listed in the "Perfect variants" section.
- **Archetype**: DPS = weapon damage builds; Skill = skill damage/repair builds; Tank = armor/bonus armor/survivability; Hybrid = mixes weapon and skill; Support = group buffs/healing.
- **Tiers** are for a typical endgame PvE player (Heroic/Legendary, raids, Countdown, Descent), with PvP noted after. **The tiers are my own judgement**, based on recurring community build guides and meta discussion (the Discord build sheet's meta builds, r/thedivision). No single authoritative tier list exists, so treat them as a starting point.
  - **S**: always keep or extract; meta.
  - **A**: strong; keep.
  - **B**: situational or niche build.
  - **C**: rarely used.
  - **D**: junk; deconstruct.
- Restriction abbreviations: AR = Assault Rifle, SMG, LMG, MMR = Marksman Rifle, Rifle, Shotgun, Pistol. "Any" = every weapon class including sidearms.

## Perfect variants (named items only – cannot be extracted to the library)

Perfect talents exist only on named items. You cannot extract them into the recalibration library, though you can recalibrate a library talent onto the named item, which replaces the perfect talent. They show the ceiling of each talent. Some are legacy "perfect" versions of talents removed from the random pool after Warlords of New York: Allegro, Accurate, Distance, Extra, Jazz Hands, Optimized.
